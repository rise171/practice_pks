# Краткое описание проекта
 Проект представляет собой мобильное приложение для управления заметками с полной реализацией CRUD-операций (создание, чтение, обновление, удаление). Цель проекта - освоение работы с локальной базой данных SQLite в среде Flutter с использованием пакета sqflite.

## Технологический стек
Flutter - кроссплатформенный фреймворк
Dart - язык программирования
sqflite - пакет для работы с SQLite
path_provider - для получения путей к директориям приложения

## Инструкция по запуску
Предварительные требования:
- Установленный Flutter SDK (версия 3.0.0 или выше)
- Настроенная среда разработки (Android Studio, VS Code или другая)
- Эмулятор или физическое устройство для тестирования

## Шаги установки
- Клонировать репозиторий проекта
- Перейти в директорию проекта
- Выполнить команду flutter pub get для установки зависимостей
- Запустить приложение командой flutter run
