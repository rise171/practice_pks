Где хранится БД: Файл базы данных app.db сохраняется в директории приложения, получаемой через getApplicationDocumentsDirectory().
Структура таблицы: Создана таблица notes с полями: id (INTEGER PRIMARY KEY AUTOINCREMENT), title (TEXT NOT NULL), body (TEXT NOT NULL), created_at и updated_at (INTEGER NOT NULL). Для хранения временных меток используется целочисленный формат Unix-time.
Индексы: Создан индекс idx_notes_created_at по полю created_at в порядке DESC для оптимизации запросов на получение последних заметок, что ускоряет сортировку и отображение списка.
CRUD-операции:
- Create: insertNote() использует db.insert() с преобразованием объекта Note в Map
- Read: fetchNotes() и searchNotes() используют db.query() с параметрами сортировки и фильтрации
- Update: updateNote() применяет db.update() с условием по id
- Delete: deleteNote() выполняет db.delete() с указанием id для удаления
