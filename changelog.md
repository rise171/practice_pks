# История Версий

## Версия 1.0.0 - Первый выпуск
Основной функционал
- Полная реализация CRUD-операций (создание, чтение, редактирование, удаление заметок)
- Локальное хранение данных в SQLite базе данных
- Поиск заметок по заголовку
- Сортировка заметок по дате создания

Технические особенности
- Использование пакета sqflite для работы с базой данных
- Поддержка миграций базы данных
- Индексация для оптимизации запросов
- Поддержка русского и английского языков

Интерфейс:
- Главный экран со списком заметок 
- Экран создания/редактирования заметок 
- Контекстное меню для быстрых действий 
- Подтверждение при удалении заметок
